## 2026-10-19: Artificial byte meaning through **learned predictive roles** (NEW, OPEN; no codec prototype yet)

**User hypothesis:** Rather than relying on human-readable semantics, let JLZ *invent* a grouping or role system that binds otherwise unrelated bytes/symbols into a predictive reusable structure. Formal model: a deterministic partition or latent state `G_t=f(X_{<t}, M_t)` computed only from previously decoded bytes and shared model state; optionally encode a role class `C_t=g(X_t,G_t)` and an exact member identity/residual. A complete code must be uniquely invertible and satisfy the *charged* minimum-description-length objective `L(model)+L(roles)+L(exact identities | roles)+L(framing) < L(existing JLZ stream)`. Online model updates must use only values already available to the decoder; per-block learned state must be serialized if it depends on unseen future bytes.

**What would count as meaning:** two different raw symbols or contexts may be assigned the same *role* when they have nearly identical next-token or next-stream conditional distributions, even when their numeric values and exact byte matches differ. This is predictive equivalence rather than human semantics; group membership must amortize a smaller shared statistical model or enable a shorter rule program. Grouping is not itself compression: for a deterministic role derived from a byte, the chain rule gives `H(X|h) = H(C|h)+H(X|C,h)`; relabeling alone cannot decrease ideal entropy. A purported improvement must come from better practical probability estimates, exploitation of non-obvious dependencies, lower coding overhead, or repeated reusable rules after model costs.

**What is already tested and MUST NOT be rediscovered:** prior predictive causal-state clustering (CS01/CS02) on older small samples, geometrical relabelings/permutations, learned latent-mask networks, sparse dependency graphs, bits-back without a useful model, nested Tietze/Re-Pair grammars (R32/R34), and short edit/template references (R45/R46). Their negatives do NOT establish results for predictive-role clustering on the *currently selected R44 internal streams*. Existing mapping audit `docs/research/complementary-integration-audit.md` explicitly identifies selected metadata and residual streams as previously untested integration surfaces for causal-state clustering.

**One bounded experiment, not a tuning campaign (OPEN):** Extract R44's *actually selected* match opcodes, copy lengths, distances, transform tags and literal residuals; optionally selected BWT symbol streams. As a zero-wire-change component test, compare prequential held-out code length of (A) current direct context model, (B) online deterministic context merging into **2–8 behaviorally equivalent role states**, and (C) a role+exact-identity two-stage arithmetic code. Require all predictive grouping to use previously decoded symbols only. Charge state labels when not decoder-derived, and count arithmetic model size, headers and CPU. Screen on **all 12 complete original Silesia inputs** with the accepted codec reference untouched, then build a full reversible native Go decoder and a ten-complete-corpus candidate-only benchmark **only if** actual selected-stream bytes show a substantial, reproducible advantage. Stop if entropy/held-out estimated savings do not survive exact native packing or incur unacceptable encode slowdown. No assertions of speed, ratio, or success yet.

**Research grounding:** computational mechanics/predictive-state equivalence, context binning/model clustering, and minimum description length. Example references: https://journals.aps.org/pre/abstract/10.1103/PhysRevE.59.275 ; https://arxiv.org/abs/2201.05028 ; https://www.scholarpedia.org/article/Minimum_description_length . This is a new *integration target and experiment plan*, not a claim that predictive clustering itself is novel.
