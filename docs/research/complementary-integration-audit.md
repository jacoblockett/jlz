# Complementary integration audit: native JLZ (Round 33)

**Status: first-pass review of every one of the 38 historical idea families plus both MDC follow-ups, NOT proof of exhaustive integrated implementation.** User directive: preserve the accepted Round 29 architecture; favor additive transforms on already selected intermediate streams, not wholesale original-byte replacement. Reject a *specific* candidate only after checking relevant complement paths or marking untested paths OPEN. Strong automatic replacement would require transformative evidence; never infer that merely from isolated sample savings.

**Surfaces to consider:** (1) currently selected byte match opcodes/lengths/distances/literals, (2) current native BWT MTF/zero-run symbol stream, (3) Round 29 modular signed-word residual low and high lanes, (4) existing independent 4-region grouping and history, (5) cheap per-stream automatic gating. Native byte-exact decoder changes and serialized bit cost are mandatory for promotion.

**Methods:** 36 original Silesia regions (7,728,404 B) tested across both additive residual coordinate streams with native packed alternative substreams and exact inverse, charging a per-changed-stream selector byte; **some of these files do not actually select additive**. A separate BWT-symbol screen used 12 regions from six Silesia files (some don't choose BWT); a match-stream screen used nine actual selected packed-match blocks sampled from 338 such blocks in previously recorded Round 25 Silesia archives, which remain byte-identical for those files in Round 29. Candidate-only ten-run full Silesia source archives were separately tested for sparse defects. These are three very different levels of evidence and must not be conflated.

## Concrete Silesia companion measurements

- **36-region additive-coordinate sample, total incumbent coordinate payload 5,966,439 B:** hypothetical per-region selective savings after a mode byte per changed lane: Tietze 16-rule hierarchy **297,313 B** (16/36); sparse zero-default defects **96,297 B** (10/36); horizontal edge-boundary **81,117 B** (8/36); vertical boundaries **61,671 B** (7/36); bitplane decomposition **26,838 B** (5/36); grid16 **3,110 B** (1/36); prime split **11 B** (2/36). XOR lags 1+2, 1+4 and 7+11 or high-XOR-low: no sample win. These are **component oracle** savings, **not** full-corpus wins. Only x-ray is known to select this coordinate coding in current approved Round 29.
- **BWT transformed-symbol screen, 12 source regions from six Silesia files, existing Huffman baseline 742,585 B:** prime index two-lane partition **1,580 B** possible selective reduction (6/12); zero-default defects **81 B** (1/12); tested grammar16, XOR, grid, and boundary streams all fail on 12/12. This is not a full archive result and several sampled files don't choose BWT as final representation.
- **Archived selected match-packed streams:** 338 such blocks available from the ten Round 29-unchanged Silesia archives (Round 25 archive bytes reused without rerunning baseline). Nine distributed blocks and three substream targets each: grammar16 saves **15,138 B** across six match-length streams of nine, with **zero gains** on the nine sampled literal or nine sampled distance streams. Prime split saves 162 B in one length stream; bitplane 26 B in one length stream; sparse, XOR, grid and geometric boundary all zero wins on the sampled selected match streams. These measurements include actually serialized alternative stream headers, models and selector byte, with exact stream reconstruction.
- **Fully integrated additive sparse-defect candidate** maintains all prior representations and chooses a new internal additive mode only if the complete new payload is strictly smaller. Across all 12 original Silesia files, candidate archive **62,147,274 B**, saving **497,389 B (0.794% of current archive)** compared with approved Round 29's **62,644,663 B**. Ten *candidate-only* whole-corpus medians: **7.944165 s encode, 3.005318 s decode**; versus *reused, separate-session* Round 29 accepted medians **7.516364/2.821363 s**, nominal **5.69% / 6.52% slower**. Every candidate run exact-roundtripped 12 Silesia sources. Targeted Go tests, vet, targeted race passed. The general uncached `go test ./...` was interrupted in this disposable research source tree with multiple unrelated long-run research tests; do not claim that sweep passed. **REJECT the specific integrated candidate** for disproportionate CPU cost despite its size benefit. No production source committed.

## Next decisions

1. **Most promising deferred integration:** fast / bounded Tietze-like coding of *selected match-length* streams, and/or cheaply preselected grammar on x-ray additive residual lanes. Require a gate based on actual redundancy, never 16 full dictionary searches per region when timing dominates. Candidate only, complete-archive measurements before promotion.
2. **Promising cheap diagnostics:** high-lane sparsity (already established) and exact finite-field low-rank predictors on bitplanes; do not mislabel simple sparse defects a complete syzygy theorem.
3. **Remaining untested but feasible:** transformations of match reference positions/mirrors, learned multivariate contexts, p-adic valuation, genuine algebraic dependency graphs, charged model state sharing within a file. Preserve them as open, not rejected.
4. **Conditional feasibility:** latent bits-back coding requires a useful latent stochastic model; external reference universe cannot silently introduce outside-file decode dependencies; content-reproducing transforms must restore exact compressed bytes, not only decoded semantics.

**No changes to the approved Round 29 engine.** This document maps all inventory families rather than treating historical negative trials as theory vetoes. Continue material, *additive* candidates from this audit alongside the user-provided active theory backlog.
