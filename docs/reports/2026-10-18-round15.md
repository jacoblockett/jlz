# Round 15: Regional pipeline early selection

**Date:** 2026-10-18. **Decision:** Approved; canonical accepted state entering repository migration.

**Hypothesis:** JLZ repeatedly codes competing streams even when a strong regional match representation should dominate. Avoid unnecessary prediction and native Huffman encoding passes, preserving existing representation selection and archive format.

**Change:** Add region-path gating to skip redundant coding work when strong matches make additional prediction/Huffman alternatives unnecessary. No user-selectable knobs or format changes. Arithmetic-first skip alone was tested separately and rejected for insufficient speed gain.

**Verification:** 27/27 input files produced archives byte-identical to Round 12, all restored byte-exactly; Go tests, static analysis and targeted race tests passed; Windows and Linux builds completed. No decoder/format changes. Initial arithmetic-first only version: 2.62% encode gain with identical archives, rejected; combined variant did not warrant incorporation.

**Caveats:** Source handoff did not include the historical paired raw CSV; this document is a canonical transcription of the approved final round report, not freshly remeasured by repo migration. Silesia input files are not redistributed in repository. Performance can vary with hardware, CPU quota and Go version.

**Next direction:** Joint token/literal entropy model and stronger architectural match reuse, avoiding a second costly search/coding pass.
