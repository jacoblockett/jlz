### H1: implicit-distance LZP native sequence stream instead of mathematical matcher or BWT

**Mechanism:** one-position 16-bit hash of 4-byte preceding source context stores previous source position. On a verified 8-byte-or-longer future equality, encode a **literal-run length plus contextual-copy length**; copy distance is implicit from the existing synchronized hash table, so no reference offsets or source-side table metadata serialized. Exact copying may overlap; encoder and decoder independently advance context hash for **every** decoded byte. Concatenated literals encoded by current `packStream`, `packFiniteState`, or `packLiteralStream` (the last including adaptive arithmetic when selected); command-length varints encoded by existing native finite-state packer. All stream counts, lengths, entropy models and native packer frames included. Three actual reversible variants.

**Results:** 36/36 exact inverse reconstructions. Actual smaller of independent current native **math or BWT region representations** summed **2,516,022 B**. Trial LZP totals: native literal pack **3,916,736 B**, finite-state literal pack **3,895,422 B**, adaptive literal pack **3,277,353 B**. Best LZP is **+761,331 B (+30.259%)** worse, **0/36** winning sampled blocks. Even without any new per-block wire mode, fails size; scanning extra source would only increase work. **REJECT concrete replacement**, not a claim that LZP+QLFC or all predictive compression is impossible. Do not tune neighbor hash widths or match lengths to obscure decisive gap.

### H2: previous-record delta before accepted periodic field packer

**Mechanism:** use known detected original `sao` **28-byte** record period. Encode per-byte XOR or modulo-256 subtraction against byte at index minus 28, then use current accepted `encodeLaneBlock(block,28)` and its per-field independent native Huffman. Inverse reconstructs sequentially using prior 28 bytes, preserving every original byte. Different placement from previously failed original **lag8** XOR feeding 8-way lanes, and unlike spatial X-ray predictors uses discovered record period.

**Results:** **all 28 natural 256 KiB blocks of original sao**, with exact inverse: current accepted raw field pack **4,941,467 B**; XOR lag28 **5,285,575 B** (+344,108, +6.964%), subtract lag28 **5,268,655 B** (+327,188, +6.621%). Single diagnostic whole-file pack-component encode costs were 77.28 ms raw, 85.94 ms XOR, 77.98 ms subtraction, excluding transform work. Both transformations expand **every block**. **REJECT this actual lag28-delta-before-field placement.** No wire decoder added.

### H3: bit-context static rANS on existing math literals

**Mechanism:** original native single-state 12-bit rANS encoding of each bit, using frequency for **8 classes of high 3 bits of preceding source-literal byte × binary prefix of current byte**, not 8 conditioned **byte-symbol** models (already tested). Two-pass measured model, deterministic Laplace smoothing, exact normalized binary probabilities; compressed 4,096-byte probability table and 4-byte initial rANS state per stream, with complete native stream framing. Decode reconstructs original stream and validates final rANS state, exact compressed table and byte counts. Distinct from previous byte-range coder preserving **adaptive** probability model. This tests whether cheap static bitwise conditional coding can remove expensive decoder-synchronous adaptation while retaining its ratio.

**Results:** 18/18 actual original Silesia region math-literal streams exact inverse (first/middle/last of mozilla, ooffice, samba, dickens, webster, osdb), with packed frequency table and framing charged. Current per-stream chosen native pack **913,452 B**; static bit-context rANS **997,565 B**, **+84,113 B (+9.208%)**; 0/18 streams improve. **REJECT this exact static-bit context placement**. The adapted probabilities provide real information not captured by its static model, and the new model transmission outweighs any speed appeal. No integrated JLZ archive candidate.
